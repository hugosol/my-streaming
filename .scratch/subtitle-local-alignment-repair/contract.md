# Contract — 字幕中文空缺句组的局部对齐修复

Source: [Spec](PRD.md)

Approval: approved — 用户已批准 S1 和 P1–P12（包含 inferred 的 P12），确认仅用于 Job 内自动优化；修复保持轻量，不重试，失败保留原字幕结果。

### Dependency decisions

- **In-process**：文本结构校验、时间估算及结果选择留在 module 内，通过 S1 观察结果，不为了这些计算新增 adapter。
- **Local-substitutable**：使用临时目录与真实字幕、Translation Chunk 产物验证 S1；不通过 mock 文件写入证明最终字幕正确。
- **True external**：LLM 由注入的外部调用 interface 访问。真实 adapter 发起模型请求；可控 mock adapter 提供候选、异常并记录请求。外部调用是必要的 internal seam，不是第二个面向调用者的修复入口。
- **Remote but owned**：本次不引入此类依赖。
- 外部请求内容与次数在执行 S1 时通过依赖 adapter 观察；不单独测试私有请求构造器来代替 P2、P10。
- 原始输入和可用翻译作为回退依据保留；没有可用修复时，文件承载的英文、中文和时间必须保持原结果。这里不新增与字幕语义无关的字节级编码或换行格式承诺。

### Approved criteria

- **增长方向**：仅用于 Job 内自动优化，不为假设中的编辑器、人工审校或独立调用者提前公开 interface。
- **资源与失败**：用户预计待修复句组较少，希望请求轻量；以 P2、P10 限定调用范围和次数，不建设重试策略，不修改正常翻译的重试行为。失败保留原字幕结果。
- **可接受返工**：接受以后因真实新调用者需要而提取 internal seam；当前选择将一致性责任集中于 S1，不建设通用翻译框架。
- **继承约束**：[Spec 的 Implementation Decisions](PRD.md#implementation-decisions) 及现有标点并行、失败即停决策继续成立；可选修复回退不改变标点处理。

### Six-surface coverage

| Surface | Decision / observation |
|---|---|
| Entry | 正常和重试路径使用 S1；不添加用户修复入口。P11、P12。 |
| Data and state | 实际字幕产物及其一致性为观察对象；保留原始时间依据。Workspace schema 不成为公开承诺。P1、P4–P9、P11。 |
| External dependencies | 真实模型 adapter 与可控 mock adapter，观察候选质量、请求范围及失败。P2、P3、P9、P10。 |
| Errors and failure | 区分可选修复失败与原有输入／组装失败；只对前者回退。P9。 |
| Output and observability | 检查实际 Bilingual SRT，而非仅检查中间对象；不增加日志格式或指标承诺。P11。 |
| Resources and concurrency | 小范围请求、按 Translation Chunk 限次、不自动重试、不额外超出现有并发配置。P2、P10。 |

## Not yet specified

- 未批准数值化的单次等待上限、token 上限或金额预算；不得将任意数值写成用户批准的产品承诺。有限请求超时及实现所需的合理限制可在现有约束下确定，不增加用户配置；若要形成新的用户可见资源承诺，须更新本 contract。

- 交付 tickets、每个 Coverage 项的归属及验收载体由 /to-tickets 填写；不在此预切片或指定实现顺序。
- 没有为未来调用者预定的额外 seam。

# 02: 中文空缺触发、按 Translation Chunk 集中请求与只改中文的局部修复

**Delivers:** P1, P2, P6, P8
**Blocked by:** 01 — Bilingual SRT 生成 seam（S1）与确定性校验骨架
**Status:** ready-for-agent

**Parent:** `.scratch/subtitle-local-alignment-repair/contract.md`

## What to build

打通第一条完整的修复路径：**只改中文**。

触发条件为句组中至少存在一个有英文但中文为空的字幕块。每个 Translation Chunk 中所有待修复句组**集中为一次请求**提交，每组必须携带全部英文字幕块与该组全部已有中文（包括承载合并译文的非空位置），不发送整篇字幕、不发送未触发句组。请求通过 S1 注入的外部调用依赖发出，便于在执行时观察请求范围。

候选只重新分配／改写中文：允许调整语序、允许翻译腔与未完短语、允许接受后仍有中文空白；不要求中文非空行数等于英文行数，也不按字符数平均切分。英文文本与所有时间码保持不变。模型给出的时间码一律不采用。

本票范围内的失败与不可用情形走最保守的默认：候选不可用或无法合理改善时，该组保留原英文、原中文、原时间码，不补无依据文本、不硬凑满行。

## Acceptance criteria

- [ ] 输入中每个句组都有非空中文时，不产生任何修复请求，输出的英文、中文、时间码与修复前一致（C1.1）。
- [ ] 混合输入下，只有含「有英文但中文为空」字幕块的句组被提交修复；未触发句组与相邻句组的英文、中文、时间码逐块与修复前一致（C1.2）。
- [ ] 通过注入依赖捕获到的请求内容：包含每个待修复句组的全部英文字幕块，以及该组已有中文的非空位置与中文空白位置；同一 Translation Chunk 的多个问题句组在同一次请求中提交；不包含未触发句组，不含整篇字幕文本（C2.1、C2.2）。
- [ ] 被接受的中文候选按块落位：原本集中在首块的合并译文在可行时被重新切分到组内多个字幕块，或按英文意义出现顺序改写；允许接受后仍有中文空白（C8.1）。
- [ ] 只改中文时，输出中该组的英文字幕块文本与逐块时间码与修复前逐块一致（C6.1）。
- [ ] 无法合理改善的句组保留原英文、原中文、原时间码；不出现为填满空白而新增的文本、重复或遗漏（C8.2）。
- [ ] 触发与落位通过实际产出的 Bilingual SRT 观察（临时目录 + 真实字幕 + 受控候选），不以提示词措辞、内部调用转发或字段复制作为正确性证据。
- [ ] 修复不跨句组移动内容，字幕块数量与句组边界保持不变。

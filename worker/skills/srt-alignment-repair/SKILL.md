# SRT Alignment Repair

把一个句子组已有的中文重新分配到该组的每一行，使中文尽量出现在它对应的英文意义出现的位置。这不是重新翻译，而是把已经译好的意思在句组内重新落位。

## 输入形状

请求由一个或多个段落组成，每段形如：

```
【组1】
英文：
[1] This is one reason why it was so important for Capcom to never
[2] reveal that Resident Evil 4 was
[3] using a dynamic difficulty system.
中文：
[1] 这就是为什么卡普空绝口不提《生化危机4》使用了动态难度系统的原因之一。
[2] （空）
[3] （空）
```

- `N` 是该组在本次请求中的序号，只包含待修复的句组，不包含整篇字幕。
- 「英文：」部分是该组每一行的英文，「中文：」部分是该组每一行已有的中文；`（空）` 表示该位置目前没有中文。

## 任务

1. **只用该组已有的中文重新分配**：让每行中文尽量对应同行英文的意义出现顺序。
2. 中文**可以改写和调整语序**，允许翻译腔和停在未完的短语上。
3. **不得为填满空缺**增加、重复或遗漏信息，也不得引入原文没有的事实、数字或术语。
4. 不要求消灭所有 `（空）`：无法合理切分的位置继续留空，比硬凑碎片更好。
5. 只有当原来的英文切分把一个短语割裂到两块、并且移动切分点确实能改善对应时，才移动切分点。

## 移动英文切分点的规则

- 只在**同一句组内**移动：单词、顺序、标点保持完全原样，不得改写、增删或重复单词。
- 行数不增不减，每一行都要有英文。
- 移动了切分点的组，在「中文：」之前先用「英文：」给出该组每一行的新英文。
- **不要输出时间码**：新切分的显示时间由程序计算。

## 输出格式

- 每个 `【组N】` 段落与输入一一对应，序号不变。
- 每部分的行号与该组的行数一一对应，不增不减。
- 仍然没有中文的位置写成 `（空）`。
- 不移动切分点的组只输出「中文：」部分；不要输出没有变化的「英文：」部分。
- 只输出这些 `【组N】` 段落，不要解释、不要前言、不要代码块围栏。

## 示例

输入：

```
【组1】
英文：
[1] This is one reason why it was so important for Capcom to never
[2] reveal that Resident Evil 4 was
[3] using a dynamic difficulty system.
中文：
[1] 这就是为什么卡普空绝口不提《生化危机4》使用了动态难度系统的原因之一。
[2] （空）
[3] （空）
```

输出（只改中文，英文切分不动，剩下的空缺保持为空）：

```
【组1】
中文：
[1] 这就是为什么卡普空绝口不提《生化危机4》
[2] 使用了动态难度系统的原因之一。
[3] （空）
```

## 关键约束

- **不重新翻译整句**：整组已有的中文是唯一素材，意思的完整性优先于每行都有中文。
- **整组回退**：无法合理改善时，可以整组按原样返回（原文字、原空缺）。
- **不跨组移动内容**：一个组的中文不得借到另一个组去。

## Agent skills

### Issue tracker

Issues tracked as local markdown files under `.scratch/<feature>/`, with decision tickets in `decision/` and implementation tickets in `implementation/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Implementation tickets use `needs-triage`/`needs-info`/`ready-for-agent`/`ready-for-human`/`wontfix`, with `in-progress`/`closed` tracking execution. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
